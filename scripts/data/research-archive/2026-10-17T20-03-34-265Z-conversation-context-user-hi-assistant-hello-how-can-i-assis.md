## Answer

TypeScript was built to give developers a safer, more maintainable way to write large JavaScript applications.  In an interview (archived note) Anders Hejlsberg explains that growing JavaScript codebases lacked strong typing and tooling, which motivated Microsoft to create a superset that adds static types and compile‑time checking. [archived]

**Key milestones (beginner‑friendly)**
- **Nov 15 2012 – TypeScript 0.8.1 announced** – the first public preview of the language, adding source‑level debugging. [INVALID CITATION 6]
- **Oct 2012 – Initial 0.8 release** (first version made available). [1][INVALID CITATION 2]
- **2016 – TypeScript 2.0** launches, introducing type inference and many modern language features. [1][INVALID CITATION 2]
- **2016‑2020 – TypeScript 3.x series** expands the type system with mapped and conditional types. [1][INVALID CITATION 2]
- **2020 – TypeScript 4.0** marks the start of the “Modern” era, adding template‑literal types and other ergonomics. [1][INVALID CITATION 2]
- **July 8 2026 – TypeScript 7.0** ships with a new Go‑based compiler and performance improvements. [1][INVALID CITATION 2]

These points give a simple picture of why TypeScript exists and the most important releases that shaped its evolution.
