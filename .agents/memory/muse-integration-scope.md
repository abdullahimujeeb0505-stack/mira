---
name: Muse integration scope
description: User-stated boundary for how Muse should acquire opportunity data.
---

Muse's opportunity and learning layers should stay provider-independent and local until the user explicitly requests integrations. The user has specifically excluded X, Photon, Web3 scraping, external APIs, schedulers, notifications, wallet access, and mint execution in this stage.

**Why:** The user wants the domain, decision, and learning layers to work before adding data providers.

**How to apply:** Do not add opportunity discovery integrations, external data acquisition, scheduling, notification delivery, wallet access, or mint execution without a new explicit request.
